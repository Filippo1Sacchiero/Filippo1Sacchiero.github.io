Project Status Watch

An AI agent that reviews the project plan every morning, flags what is late or at risk, and drafts the weekly status report, so the project manager only has to check it and send it.

Filippo Sacchiero · MDBM, Hochschule Pforzheim · Prof. Dr. Pin Luarn

The problem

In most companies the weekly project status report is still put together by hand, from several spreadsheets, every Friday.

1

The status report eats the Friday

Collecting progress from every workstream, checking dates and budgets and writing the summary takes hours of a project manager's week, every week.

2

Problems are seen too late

A task that slowly falls behind looks fine until its due date has passed. By then the milestone that depends on it is already in danger.

3

Everybody reads a different status

"Green" means something different to every workstream lead. Without fixed rules the traffic lights depend on who fills them in.

How it works

The agent orchestrates the work and writes the texts. The numbers are calculated in tested code, because language models are good with language but not reliable with arithmetic.

Status rules

The same rules for every workstream, written down once and implemented one-to-one in the engine. Each rule has its own unit test.

Task status

StatusWhen
DoneProgress is 100 %
LatePast the due date and not done
At risk20 or more points behind the planned progress, or due within 7 days and below 80 %
Not startedStart date is still in the future
On trackEverything else

Planned progress = days passed ÷ task duration (steady work from start to due date)

Workstream and project status

StatusWhen
RedA late milestone, two or more late tasks, or SPI / CPI below 0.85
AmberAny late or at-risk task, SPI / CPI below 0.95, or an open risk with probability × impact ≥ 15
GreenNone of the above

SPI (schedule) = earned value ÷ planned value · CPI (cost) = earned value ÷ actual cost
Below 1 means behind schedule or over budget. The project takes the status of its worst workstream.

      Next steps

      Live data source

      Read the plan from a shared Google Sheet or directly from the project tool (e.g. Jira), so workstream leads update progress where they already work.

      Approval in n8n

      Send the Friday drafts to the project manager, collect a one-click approval, then send the emails and file the report.

      Confidential projects

      Write the drafts with a local model (Ollama), so internal project data never leaves the company network.
